# Deeksha Gowda Portfolio — Complete Frontend

This is the complete React/Vite frontend for the portfolio.

## Included
- Portfolio pages and sections
- Projects and project information
- Skills, experience, education and contact sections
- Existing assets used by the application
- Formspree contact form endpoint
- Vite/React configuration

## Important
The `public` folder does not need to contain the portfolio content. In a React/Vite app, most of the visible website is rendered from the `src` folder.

## GitHub
Upload the CONTENTS of this project folder to your GitHub repository (not the ZIP file).

## Vercel
Use:
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- No environment variables are required for the Formspree contact form.
